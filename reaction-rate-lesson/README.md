# 화학 반응 속도

화학 반응 속도의 정의와 그래프 해석 방법을 다루는 수업용 인터랙티브 프레젠테이션입니다 (20장).

## 파일

- `index.html` — 클릭하면 내용이 하나씩 나타나는 발표용 웹 슬라이드 (시뮬레이션 포함, 파일 하나로 동작)
- `images/slide-01.png` ~ `slide-20.png` — 슬라이드별 이미지 (1920×1080, 모든 내용이 펼쳐진 상태, 시뮬레이션은 시작 전 화면)

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 보기/숨기기 |
| P | 판서 모드 켜기/끄기 (색: 빨강·파랑·검정·형광펜) |
| C | 현재 슬라이드 판서 지우기 |

## 인터랙티브 요소

| 슬라이드 | 내용 |
| --- | --- |
| 2 배경지식 | 2H₂ + O₂ → 2H₂O 원자 재배열 애니메이션, 달리기로 보는 "속도 = 변화량 ÷ 시간" |
| 3 Δ로 나타내기 | 사탕 개수로 보는 Δ(+4개 · −4개), Δ[X]/Δt 뜻과 단위(M/s), 오늘의 핵심 목표, A → B의 v = Δ[B]/Δt = −Δ[A]/Δt (클릭마다 하나씩) |
| 4 반응 속도 | A → B 입자 시뮬레이션 + 실시간 농도 그래프, 최근 10초 소모·생성 속도 계산 |
| 6 활동 1 풀이 | 반응량·시간 슬라이더로 바뀌는 N₂·H₂·NH₃ 속도와 농도 막대 |
| 10 그래프 해석 | t₁·t₂를 끌어 평균(두 점 직선)·순간(접선) 반응 속도 비교, "Δt → 0" 애니메이션 |
| 12 활동 3 풀이 | 클릭마다 20 s 접선 → 평균 직선 → 40 s 접선이 나타남 |
| 13 심화 | 입자 충돌 시뮬레이션(2A → 3B): 시간이 갈수록 충돌·반응 횟수가 줄어드는 모습, 처음 입자 수 조절 |
| 14 확인 문제 | 누를 때마다 새로 출제되는 랜덤 반응 속도 문제와 풀이 |
| 15·16 개념 정리 | 반응식과 그래프에서 반응 속도를 구하는 3단계, 확인 문제 (클릭마다 하나씩) |
| 17·18 수능형 문제 | 시험지 형식의 문항과 클릭마다 나타나는 정답 및 해설 |

## 주소 옵션

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
- `index.html?export`는 `?all`과 같지만 화면 아래 안내 문구를 숨깁니다.
- `index.html?print`로 열고 인쇄하면 한 장에 한 슬라이드씩 PDF로 저장됩니다 (시뮬레이션은 끝난 상태로 인쇄).
