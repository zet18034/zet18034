# 객체 높임과 상대 높임 (2차시)

화법과 언어 3단원 「(1) 문장의 짜임과 문법 요소」 2차시 수업용 프레젠테이션입니다.
객체 높임법과 상대 높임법을 다룹니다. (1차시: [honorific-lesson-1](../honorific-lesson-1/))

## 파일

- `index.html` — 클릭하면 내용이 하나씩 나타나는 발표용 웹 슬라이드 (26장)
- `lesson-plan/lesson-plan-2.pdf` · `.hwp` — 2차시 교수·학습 과정안(세안)

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 보기/숨기기 |

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
- `index.html?print`로 열고 인쇄하면 한 장에 한 슬라이드씩 PDF로 저장됩니다.
