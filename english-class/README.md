# The Model Millionaire (Special Lesson 1 · 1차시)

High School English Ⅱ Special Lesson 「The Model Millionaire」(Oscar Wilde) 1차시 수업용 프레젠테이션입니다.
원래 PPT(`Special Lesson 1.pdf`)의 흐름을 따르면서 수업안의 단계(도입 – 전개 – 정리)에 맞게 구체화했습니다.

## 파일

- `index.html` — 클릭하면 내용이 하나씩 나타나는 발표용 웹 슬라이드 (30장)
- `assets/` — 원래 PPT에서 가져온 이미지 (잡지 표지, 포스터, 거지 삽화, 패들렛 QR)

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트(영어 대본) 보기/숨기기 |
| 타이머 클릭 | 타이머 시작/일시정지 · R: 초기화 |

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
- `index.html?print`로 열고 인쇄하면 한 장에 한 슬라이드씩 PDF로 저장됩니다.
