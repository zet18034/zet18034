관리자 화면 연결하기 (처음 한 번, 약 5분)

학생 기기 여섯 대의 진행 상황을 한곳에 모으려면 선생님 구글 계정의 Google 시트를 저장소로 씁니다. 학생은 로그인할 필요가 없고, 기록에는 팀 번호·팀 이름·푼 카드만 남습니다.

  1. Google 드라이브에서 새로 만들기 → Google 스프레드시트를 만들고 이름을 ‘출제 본부 탈출 기록’ 정도로 바꿉니다.
  2. 시트 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
  3. 편집기에 있던 코드를 모두 지우고 아래 코드를 붙여 넣은 뒤 Ctrl+S로 저장합니다. 
    4. 
    
  4. 오른쪽 위 배포 → 새 배포를 누르고, ‘유형 선택’ 톱니바퀴에서 웹 앱을 고릅니다.
    
      · 다음 사용자 인증 정보로 실행: 나
    · 액세스 권한이 있는 사용자: 모든 사용자
    그리고 배포를 누릅니다.
    5. 
    
  5. 권한 승인 창이 뜨면 선생님 계정을 고르고, ‘확인되지 않은 앱’ 경고가 나오면 고급 → (프로젝트 이름)(으)로 이동 → 허용을 누릅니다. 직접 만든 스크립트라 뜨는 정상적인 경고입니다.
    6. 
    
  6. 마지막 화면의 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해 관리자 페이지 ①의 주소 칸에 붙여 넣고 저장하고 연결을 누릅니다.
    7. 
    
  7. 수업 전에 관리자 페이지의 게임 열기로 한 팀을 시험해 보고, 관리자 화면에 팀이 뜨는지 확인합니다.
    8. 
  

  

    
‘연결 오류’가 날 때 확인할 것

    
① 주소가 https://script.google.com/macros/s/…/exec 로 끝나는지 (편집기 주소나 …/dev 주소가 아님)

    ② 배포할 때 액세스 권한이 ‘모든 사용자’인지 (‘Google 계정이 있는 모든 사용자’는 안 됨). 학교 구글 계정이라 ‘모든 사용자’가 목록에 없으면 개인 Gmail 계정으로 시트를 만들어 주세요.

    ③ 코드를 고친 뒤에는 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 해야 반영됩니다. (새 배포를 하면 주소가 바뀌니 새 주소를 다시 넣기)

    ④ 주소를 브라우저 새 탭에 붙여 넣어 열었을 때 {"last":…} 같은 글자가 나오면 서버는 정상입니다. 로그인 화면이나 오류가 나오면 ②·③을 다시 확인하세요.
