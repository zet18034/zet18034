# 문장 종결 표현과 높임 표현 (3차시)

화법과 언어 3단원 「(1) 문장의 짜임과 문법 요소」 3차시 모둠 수업 자료입니다.
교과서 107쪽 탐구 활동, 활동지 「높임의 대상 찾기」, 수능 기출 문제(언어와 매체)를 4~5인 모둠으로 함께 풉니다.
(1차시: [honorific-lesson-1](../honorific-lesson-1/) · 2차시: [honorific-lesson-2](../honorific-lesson-2/))

## 방탈출 활동 「출제 본부를 탈출하라」 (초안)

활동지와 수능 기출을 카드 탐색형 방탈출로 푸는 웹 프로그램과 단서지입니다. 혼자 또는 둘이서 기기 한 대로 접속합니다(태블릿·노트북 권장).

- `escape/index.html` — 방탈출 프로그램
  - **평면도**에서 방으로 들어가고, 방 그림 속 번호를 눌러 카드를 뽑습니다. 카드 안 밑줄 번호를 누르면 또 다른 카드가 나오고, 그림 곳곳에 흐릿한 **숨은 번호**가 있습니다(복도 자판기 포함).
  - 우편실(활동지 1·3·4번): 빨간 인물 카드 + 파란 표현 카드를 **맞대어** 표현이 누구를 높이는지 찾습니다. 맞는 짝은 확인 카드, 헷갈린 짝은 **경보 카드**(오개념 설명 + 벌점)가 나옵니다. 확인 도장 9개 → 금고 다이얼.
  - 식당(간접 높임·사물 높임, 활동지 7번): 본부 곳곳의 응대 문구 카드 가운데 잘못 높인 다섯 장의 번호 합을 경보기에 넣고, 수리 키트로 7번을 고칩니다.
  - 출제실(2026 수능 37번) · 검토실(2022학년도 9월 모평 38번): 조건 검사기·성분 추적기에 분석 결과를 넣고 검토 의견서로 정답을 고릅니다. 흔한 오답에는 맞춤 피드백이 나옵니다.
  - 정문: 열쇠 조각 네 개(태·도·화자·의)로 성취기준 ‘화자의 태도’를 완성합니다.
  - 힌트·숨은 번호 탐지기는 한 번에 +1분, 경보 카드와 틀린 비밀번호는 +30초입니다. 탈출하면 별점과 기록 카드가 나옵니다.
  - 제한 시간은 기본 35분이고, `?min=30`처럼 주소에 붙여 바꿀 수 있습니다.
  - 진행 상황은 그 기기에만 저장되므로 새로 고쳐도 이어집니다.
  - 오른쪽 아래 ‘교사’ 버튼은 교사 번호를 넣으면 막힌 장치를 통과시키거나 처음부터 다시 시작하게 합니다.
- `escape/worksheet.html` — 단서지(A4 3쪽, 학생 한 명에 한 부, 숨은 카드는 빈칸으로 둠). `worksheet.html?key`로 열면 교사용 정답본이 됩니다.
- `escape/worksheet.pdf` · `escape/worksheet-key.pdf` — 인쇄용 PDF

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 보기/숨기기 (과정안의 교사 발화) |

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
