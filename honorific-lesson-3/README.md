# 출제 본부 탈출: 높임 표현 × 문장의 짜임 (3차시)

화법과 언어 3단원 「(1) 문장의 짜임과 문법 요소」 3차시(마지막 차시) 수업 자료입니다.
처음에는 평범한 수업처럼 교과서 107쪽으로 전시 학습을 점검하고 팀을 나눈 뒤, 화면이 공포 분위기로 바뀌며 방탈출임이 드러납니다. 4~5인 6팀이 방탈출 게임 「출제 본부 탈출」로 높임 표현과 문장의 짜임이 함께 적용된 문장(수능·모의평가 기출 문항에서 따옴)을 분석합니다. 교사는 관리자 페이지로 팀별 카드 진행과 문제별 오답을 실시간으로 보고, 막힌 팀은 그 자리에서 통과시킵니다. 정리 단계의 시상·오답 TOP 3 슬라이드는 그 기록으로 자동으로 채워집니다.
(1차시: [honorific-lesson-1](../honorific-lesson-1/) · 2차시: [honorific-lesson-2](../honorific-lesson-2/))

필수 12문항은 고2 학생이 문장 하나를 분석하고 팀이 근거를 맞춰 보는 데 1분 30초~2분, 해설 읽기와 검토 일지 해독표 ○(문항당 10~20초)까지 더해 평균 26~29분에 끝나도록 잡았습니다. 늦어지는 반은 `?min=32`처럼 제한 시간을 늘릴 수 있습니다. 먼저 끝낸 팀은 보너스 4문항으로 남은 시간을 씁니다.

| 단계 | 슬라이드 |

- 1~4번은 1·2차시와 같은 평범한 수업 화면이고, 팀 편성 슬라이드에도 게임 낱말을 넣지 않았습니다. 5번으로 넘어가는 순간 화면이 정전된 듯 깜빡이며 바뀌고 **배경 음악이 자동으로 켜집니다**(끄고 켜기는 **M 키**, 크기는 `index.html` 끝의 `VOL`).
- 5~20번은 게임과 같은 공포 분위기(붉은 비상등, 어두운 화면)로 꾸몄습니다.
- 8~18번의 게임 화면은 플레이 예시 **ROOM 0 ‘경비실’**로 찍었습니다(예: 15 + 28 = 43, 해독표 글자 ‘손전등’ → 열쇠 3). 실제 문제와 답은 슬라이드에 나오지 않습니다.
- 관리자 기록이 없으면 21~25번에는 예시 문제와 ○ 자리가 나옵니다.

## 방탈출 「출제 본부 탈출」

늦은 밤 정전된 출제 본부에서 봉인되기 전에 빠져나가는 카드형 방탈출입니다. 4~5명이 한 팀, 6팀이 각각 기기 한 대를 씁니다(태블릿·노트북 권장).

- `escape/index.html` — 게임
  - 시작할 때 팀 번호(1~6)와 **팀 이름**을 정합니다.
  - **평면도**에서 방을 누르면 말이 이동해 방으로 들어갑니다. 위에서 내려다본 방 그림을 손전등으로 비추며 **번호 동그라미**를 누르면 카드가 책상에 놓입니다. 게임 중에는 가운데 책상과 검토 기록만 스크롤됩니다.
  - 동그라미 색: 빨강 = 잠긴 물건·문제(필수), 노랑 = 보너스(어렵지만 맞히면 남은 시간 +2분), 파랑 = 도구·단서, 초록 = 장치 퍼즐.
  - **번호 결합**: 방 그림(검색실 검색대 위 4 · 식당 의자 밑 바닥 3 · 검토실 파쇄기 옆 바닥 6)이나 단서 그림(출제실 문법 사전 5) 속 숨은 번호로 도구를 찾고, 잠긴 물건 번호 + 도구 번호를 단말기의 **번호 입력**에 넣으면 문제 카드가 나옵니다(검색실 8·21 + 4 → 12·25, 식당 11·23 + 3 → 14·26, 출제실 11·22 + 5 → 16·27, 검토실 12·23 + 6 → 18·29). 잘못된 번호는 시간이 줄지 않습니다.
  - **숨은 보너스(이스터에그)**: 번호를 번호 입력에 넣으면 카드가 나오고, 맞히면 남은 시간 +1분입니다. 62 = 평면도 복도의 비상등 아래(손전등을 대면 보임), 73 = 구내식당 해제 화면 오른쪽 아래, 86 = 평면도 비상구 문 안쪽, 91 = 평면도에서 잠긴 검토실의 작은 창. ‘다음 할 일’과 검토 일지에는 나오지 않습니다.
  - **다음 할 일** 띠를 누르면 지금 할 카드로 바로 넘어갑니다.
  - 문제는 5지선다이며 정답 번호를 고르게 나누고 어려운 문제는 ④·⑤에 두었습니다. 설명형 외에 ‘적절하지 않은 것’과 조건에 맞는 문장을 고르는 유형(25·29·71·보너스 31)이 있습니다. 맞히면 **번호**와 **자세한 해설**이 나옵니다.
  - **장치 퍼즐**(빨간 문제를 다 풀어야 전원이 켜짐): 검색실 = 톱니로 맞물린 다이얼, 식당 = 사물 높임 퓨즈판(합 53), 출제실 = 서술어 자릿수 레버와 숫자판(84), 검토실 = 높임 대상과 문장 성분 배선(45).
  - 장치가 열리면 안에서 **금고 속 서류**(58 · 66 · 71 · 83)가 나옵니다. 이것까지 맞히면 **열쇠 상자**가 나오고, 상자는 종이 **검토 일지의 암호 해독표**에서 바르게 고른 글자 세 개로만 열립니다. 열면 장치 비밀번호의 일의 자리가 그 방의 **열쇠 숫자**입니다.
    - 해독표 글자: 검색실 ‘우편물’(우편함·우체통) · 식당 ‘배식구’(배수구·배식대) · 출제실 ‘시험지’(시험장·시안지·시간표) · 검토실 ‘비상구’(비상문·비밀문·비밀실). 정답의 첫 글자를 맞혀도 둘째·셋째 글자가 모두 갈리게 짰습니다. 틀리면 경보, 남은 시간 −30초.
    - 검색실 금고 26 + 21 = 47 → 7 · 식당 경보기 75 − 22 = 53 → 3 · 출제실 의견서 50 + 34 = 84 → 4 · 검토실 추적기 63 − 18 = 45 → 5 · 비상구 7345
  - 보안 검색실(명사절·서술절·인용절 속 높임) → 구내식당(간접 높임·사물 높임) → 출제실(서술어 자릿수·‘-시-’, 2026 수능 37번의 핵심) → 검토실(안긴문장의 높임 대상과 안은문장의 성분, 2022학년도 9월 모평 38번의 핵심).
  - 틀리면 경보와 함께 왜 틀렸는지 설명이 나오고, 남은 시간에서 30초가 바로 빠집니다. 힌트는 −1분, 보너스는 +2분입니다. 0이 지나면 초과 시간을 셉니다. 제한 시간 기본 30분(`?min=35`처럼 변경).
  - **배경 음악**: 낮은 드론, 바람 소리, 멀리서 들리는 오르골, 가끔 삐걱임(`escape/bgm.js`, 파일 없이 브라우저에서 만듦). 남은 시간이 5분 아래면 긴장이 오르고 심장 소리가 납니다. 단말기의 ‘소리’ 버튼으로 끄고 켭니다. 크기는 `index.html`의 `BGM_VOL`.
  - 관리자 페이지와 연결하지 않은 수업에서만 왼쪽 아래 ‘교사’ 버튼(번호 1110)이 보입니다.
- `escape/admin.html` — **관리자 페이지**
  - 학생 접속 QR, 모든 팀 일시정지·공지 보내기
  - **팀별 진행 상황 · 교사 메뉴**: 방마다 카드 칸(안 엶 / 열어 봄 / 틀림과 경보 횟수 / 해결 / 선생님 통과, 🔑 = 열쇠 상자), 마지막으로 본 카드, 3분 넘게 멈춘 팀 표시. 카드 칸을 누르면 그 카드만 통과, ‘방 통과’, ‘비상구 통과’, ‘이 팀에만 공지’, ‘처음부터 다시’. 각 기기에 8초 안에 반영됩니다.
  - 문제별 오답과 가장 많이 고른 오답, 오답 TOP 3, 순위, CSV 내려받기
- `escape/short.js` · `../e/` — 짧은 접속 주소 **zet18034.github.io/zet18034/e** (short.js의 `api`에 웹 앱 주소를 넣으면, 관리자 페이지에서 저장한 수업 코드로 자동 연결)
- `escape/setup.html` — 관리자 페이지 연결 방법 (처음 한 번, Google 시트 + Apps Script, 약 5분)
- `escape/apps-script.gs` — Google Apps Script에 붙여 넣을 기록 서버 코드
- `escape/cards.js` — 방·카드 데이터 · `escape/live.js` — 연결·집계·명령 코드 · `escape/bgm.js` — 배경 음악 (게임·관리자·슬라이드가 함께 씀)
- `escape/worksheet.html` — 검토 일지 (A4 2쪽, 학생 한 명에 한 부). 카드마다 고른 답과 **암호 해독표**(질문 하나에 세 칸, ○한 칸의 글자가 열쇠 상자 글자)가 있어 게임에 꼭 필요합니다. 판정 내용은 `cards.js`에서 읽어 게임과 어긋나지 않습니다. `worksheet.html?key`는 교사용 정답본. 인쇄용 `worksheet.pdf` · `worksheet-key.pdf`

### 수업 당일 순서

1. 선생님 컴퓨터에서 `escape/admin.html`을 열고 수업 코드를 새로 만들어 저장합니다(처음이면 `setup.html`대로 연결).
2. **같은 브라우저**로 발표 슬라이드를 엽니다. 15번 슬라이드 QR이 이 수업에 연결된 주소가 됩니다.
3. 수업 중에는 관리자 페이지로 진행을 보고 막힌 팀을 통과시킵니다. 게임이 끝나면 슬라이드의 오답 TOP 3와 시상이 자동으로 채워집니다.

※ 관리자 페이지와 슬라이드는 둘 다 `zet18034.github.io` 주소로 열어야 서로 연결됩니다. 관리자 연결이 없어도 게임 자체는 그대로 진행됩니다.
