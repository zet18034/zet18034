# 문장 종결 표현과 높임 표현 (3차시)

화법과 언어 3단원 「(1) 문장의 짜임과 문법 요소」 3차시 모둠 수업 자료입니다.
교과서 107쪽 탐구 활동, 활동지 「높임의 대상 찾기」, 수능 기출 문제(언어와 매체)를 4~5인 모둠으로 함께 풉니다.
(1차시: [honorific-lesson-1](../honorific-lesson-1/) · 2차시: [honorific-lesson-2](../honorific-lesson-2/))

## 파일

- `index.html` — 클릭하면 내용이 하나씩 나타나는 발표용 웹 슬라이드 (21장, 초안)
- `honorific-lesson-3.pdf` — 전체 21장 PDF (모든 내용이 펼쳐진 상태)
- `assets/` — 교과서 107쪽 그림, 수능 기출 문항 이미지
- `lesson-plan/lesson-plan-3.pdf` · `.hwp` · `.hwpx` — 3차시 교수·학습 과정안 (1·2차시와 같은 양식, 교사 발화 포함)
- `lesson-plan/lesson-plan-3-onepage.pdf` · `.hwp` · `.hwpx` — 3차시 교수·학습 과정안 (1쪽 약안)

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 보기/숨기기 (과정안의 교사 발화) |

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
