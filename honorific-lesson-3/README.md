화법과 언어 3단원 「(1) 문장의 짜임과 문법 요소」 3차시 모둠 수업 자료입니다.
교과서 107쪽 탐구 활동, 활동지 「높임의 대상 찾기」, 수능 기출 문제(언어와 매체)를 4~5인 모둠으로 함께 풉니다.
(1차시: [honorific-lesson-1](../honorific-lesson-1/) · 2차시: [honorific-lesson-2](../honorific-lesson-2/))

## 방탈출 활동 「출제 본부 탈출」 (초안)

높임 표현과 문장의 짜임을 함께 묻는 수능형 문제를 보드게임(카드형 방탈출) 느낌으로 푸는 웹 프로그램과 검토 일지(활동지)입니다. 늦은 밤 정전된 출제 본부에서 봉인되기 전에 빠져나가는 공포 분위기이며, 4~5명이 한 팀으로 기기 한 대를 씁니다(태블릿·노트북 권장).

- `escape/index.html` — 방탈출 프로그램
  - **평면도**(게임판)에서 방을 누르면 말이 이동해 방으로 들어갑니다. 방은 위에서 내려다본 **방 카드**로 나오고, 손전등이 비추는 그림 속 번호를 누르면 그 번호의 카드가 뒤집혀 책상 위에 놓입니다.
  - 카드 색: 빨강 = 필수 문제, 노랑 = 보너스 문제(맞히면 −30초), 파랑 = 단서, 초록 = 장치. 빨간 카드 두 장의 숫자로 장치를 열면 **열쇠 숫자**를 얻고 다음 방이 열립니다.
  - 문서 수발실(명사절·서술절 속 높임) → 구내식당(간접 높임·사물 높임) → 출제실(서술어 자릿수·‘-시-’, 2026 수능 37번의 핵심) → 검토실(안긴문장의 높임 대상과 안은문장의 성분, 2022학년도 9월 모평 38번의 핵심) → 비상구(열쇠 숫자 7345).
  - 필수 8문항 + 보너스 4문항. 문장은 모두 새로 만든 수능형이며 ‘이 문장에 대한 설명으로 적절한 것은?’ 형식입니다. 예상 소요 시간은 23~25분입니다. 틀리면 **경보**(+30초)와 함께 왜 틀렸는지 설명이 나오고, 힌트는 +1분입니다.
  - 화면 위 ‘다음 할 일’ 띠가 지금 해야 할 일을 알려 주고, 풀 차례가 된 장치는 반짝입니다.
  - **본부 단말기**(오른쪽): 타이머, 열쇠, 벌점, 평면도·일시정지·소리 버튼, 검토 일지(푼 카드와 경보 기록).
  - 제한 시간은 기본 30분이고 `?min=35`처럼 바꿀 수 있습니다. 진행 상황은 그 기기에 저장됩니다.
  - 왼쪽 아래 ‘교사’ 버튼: 교사 번호를 넣으면 카드·방 통과, 처음부터 다시 시작.
- `escape/worksheet.html` — 검토 일지(A4 2쪽, 학생 한 명에 한 부). 카드마다 고른 답과 근거를 적습니다. `worksheet.html?key`로 열면 교사용 정답본이 됩니다.
- `escape/worksheet.pdf` · `escape/worksheet-key.pdf` — 인쇄용 PDF

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 인터넷이 연결되어 있어야 글꼴이 제대로 나옵니다.

| 키 | 동작 |
| --- | --- |
| → / 스페이스 / 클릭 | 다음 (클릭할 때마다 내용이 하나씩 나타남) |
| ← / 오른쪽 클릭 | 이전 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 보기/숨기기 (과정안의 교사 발화) |

- `index.html#slide-5`처럼 주소 끝에 붙이면 5번 슬라이드부터 시작합니다.
- `index.html?all`로 열면 모든 내용이 처음부터 다 펼쳐진 상태로 보입니다.
